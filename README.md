# 📈 台股分析儀表板

自動掃描台灣股市，整合技術指標、三大法人、融資融券、借券資料，找出短線強弱與中長線訊號，並支援 Excel 下載與財經新聞瀏覽。

## 功能模式

| 模式 | 說明 |
|------|------|
| 📋 全市場掃描 | 從證交所抓取成交量前 N 大個股，進行中長線技術分析，支援精選25支 / ETF成分股 / 全市場三種範圍 |
| 📅 近期強弱掃描 | 以 5 / 10 / 15 / 30 日短線評分，找出近期強弱格局，含三大法人連續買賣超方向，支援 Excel 下載 |
| 🔍 個股查詢 | K 線圖、布林帶、MACD、RSI、均線一次看，附相關新聞 |
| 📊 各股技術分析 | 日K線 + 成交量 + KD + MACD 四合一圖表，三大法人與融資融券歷史柱狀圖，附交易明細彙整表 |

## 訊號說明

### 中長線（全市場掃描）

| 訊號 | 評分 | 說明 |
|------|------|------|
| 🟢 被錯殺 | ≥ 50 | 多重技術指標超賣，可研究買進 |
| 🔵 考慮買進 | 20–49 | 出現買進訊號，留意觀察 |
| ⚪ 觀望 | -15 到 19 | 無明確訊號 |
| 🟠 偏空觀望 | -40 到 -16 | 技術面偏弱，謹慎操作 |
| 🔴 注意退場 | ≤ -40 | 多重空頭訊號，考慮減碼 |

### 近期強弱掃描（短線）

| 訊號 | 評分 | 說明 |
|------|------|------|
| 🔥 強勢多頭 | ≥ 50 | 動能、量能、法人全面偏多 |
| 🟢 短期偏多 | 25–49 | 短線偏多格局 |
| ⚪ 盤整觀望 | -24 到 24 | 無明確方向 |
| 🟠 短期偏空 | -25 到 -49 | 短線偏弱 |
| 🔴 弱勢空頭 | ≤ -50 | 動能、量能、法人全面偏空 |

## 技術指標

### 中長線指標
- **RSI**（14日）：超賣 <30 / 超買 >70
- **MACD**：EMA12 / EMA26 / Signal9，黃金交叉 / 死亡交叉
- **布林帶**：MA20 ± 2σ
- **均線交叉**：MA5 / MA20
- **量比**：今日量 ÷ 5日均量
- **KD**（9日）：K = 前K×2/3 + RSV×1/3，初始值 50

### 短線指標（近期強弱掃描）
- N 日累積漲跌幅（動能）
- 量比 × 漲跌方向（量能）
- MA5 位置與斜率
- N 日新高 / 新低突破
- KD 位置與交叉
- 三大法人連續買賣超天數

## 法人資料整合

| 資料 | 來源 | 更新頻率 |
|------|------|---------|
| 三大法人買賣超 | TWSE T86 API | 盤後每日 |
| 融資融券 | TWSE MI_MARGN API | 盤後每日 |
| 借券餘額／賣出 | TWSE TWT93U API | 盤後每日 |

## 資料來源

| 類型 | 來源 |
|------|------|
| 股價資料 | Yahoo Finance（yfinance） |
| 全市場股票清單 | 台灣證券交易所公開 API |
| ETF 成分股 | wantgoo.com（失敗時使用快取） |
| 財經新聞 | 鉅亨網、Yahoo 財經、聯合報、工商時報 RSS |

## 安裝與執行

```bash
# 安裝套件
pip install -r requirements.txt

# 啟動
python -m streamlit run app.py
```

開啟瀏覽器前往 `http://localhost:8501`

## 專案結構

```
stocknew/
├── app.py                    # Streamlit 主介面（四大功能模式）
├── data_fetcher.py           # 個股資料抓取（yfinance）
├── market_fetcher.py         # 全市場清單（證交所 API）
├── technical_analysis.py     # 技術指標計算、中長線 & 短線訊號
├── screener.py               # 選股篩選（全市場 / ETF / 近期強弱）
├── institutional_fetcher.py  # 三大法人、融資融券、借券資料（TWSE API）
├── etf_fetcher.py            # ETF 成分股爬取
├── news_scraper.py           # 新聞蒐集（RSS）
└── requirements.txt          # 套件清單
```
